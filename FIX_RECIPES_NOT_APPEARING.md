# 🔧 Почему рецепты не добавляются в Firebase

## 🔍 Диагностика

Если после нажатия "Начать импорт" рецепты не появляются в Firebase, главная причина - **правила безопасности Firestore**.

## ✅ Решение (3 шага)

### Шаг 1️⃣: Откройте Firebase Console

```
https://console.firebase.google.com/project/edafit-f3738
```

### Шаг 2️⃣: Перейдите в Firestore Rules

1. В левом меню нажмите **Firestore Database**
2. Откройте вкладку **Rules** (Правила)

### Шаг 3️⃣: Замените текущие правила

**Найдите текущие правила** и замените на это:

```yaml
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /recipes/{document=**} {
      allow read: if true;
      allow write: if true;
    }
  }
}
```

**Нажмите кнопку Publish** (Опубликовать)

## 🚀 После обновления правил

4. Нажмите "Начать импорт"

## 🐛 Если не работает

### Проверка 1: Логи ошибок

Откройте VS Code и смотрите вывод консоли:

```
❌ Ошибка импорта: PERMISSION_DENIED: Missing or insufficient permissions
```

**Это значит**: Правила безопасности не обновились или не опубликовались

**Решение**: 
- Убедитесь что вы нажали **Publish**
- Подождите 1-2 минуты
- Перезагрузите приложение

### Проверка 2: Сеть

Убедитесь что:
- Приложение имеет интернет
- Вы не используете VPN
- Firebase проект активен

### Проверка 3: Правила безопасности

Откройте Firebase → Firestore → Rules и убедитесь что они совпадают с примером выше

## 🔐 Безопасные правила (для продакшена)

Когда тестирование закончится, используйте более строгие правила:

```yaml
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Только аутентифицированные пользователи могут читать
    match /recipes/{document=**} {
      allow read: if request.auth != null;
      // Только для тестирования - позволяем писать
      allow write: if request.auth != null;
    }
  }
}
```
